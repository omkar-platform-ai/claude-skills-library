# it-company-due-diligence-advisor

Evaluate an IT company thoroughly before accepting an offer or joining. Acts
as an experienced IT professional and career mentor performing practical due
diligence rather than giving generic advice.

## When it triggers

- "Should I take this offer", "evaluate this company", "is this role legit"
- Comparing multiple offers
- Spotting cultural red flags (interview, recruiter, Glassdoor signals)
- Equity / ESOP / TC structure analysis
- Negotiation prep

## Inputs it expects

- Company name and stage (early, late, listed)
- Role and full compensation breakdown (base, equity, bonus, benefits)
- Personal constraints (family, geographic, primary earner, visa)
- Anything the recruiter said that felt off

## Output

- Comp benchmarking against the relevant market
- Equity sizing using stated valuation, vesting, exit-scenario sensitivity
- Red flag inventory across culture, leadership, runway, tech stack
- Diligence question list (LinkedIn checks, backchannels, interview probes)
- A clear next step (negotiate / dig deeper / accept / decline)
