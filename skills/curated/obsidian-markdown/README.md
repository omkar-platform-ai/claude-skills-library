# Obsidian Flavored Markdown Skill

Create and edit valid Obsidian Flavored Markdown — wikilinks, embeds,
callouts, properties, comments, highlights, math, Mermaid diagrams, and
footnotes. Covers Obsidian's extensions on top of CommonMark and GFM.

## Skill Structure

```text
obsidian-markdown/
├── SKILL.md
├── README.md
└── references/
    ├── CALLOUTS.md     ← Full callout types with aliases and CSS callouts
    ├── EMBEDS.md       ← Audio, video, search, and external image embeds
    └── PROPERTIES.md   ← All frontmatter property types and tag syntax
```

## How to Trigger

Invoke naturally by saying things like:

- "Create an Obsidian note for this meeting"
- "Add a warning callout to this note"
- "Link this note to my 'Project Alpha' note"
- "Embed this image at width 600"
- "Set frontmatter properties on this file"

## What You Get

Valid Obsidian Flavored Markdown files using:

- `[[Wikilinks]]` for internal vault navigation
- `![[Embeds]]` for inlining other notes, images, PDFs, audio, video
- `> [!type]` callouts with collapsible variants
- YAML frontmatter for properties, tags, aliases, CSS classes
- `==Highlighted==` text, `%%hidden comments%%`, LaTeX math, Mermaid
  diagrams, and footnotes
